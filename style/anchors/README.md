# 风格锚点（anchors）

这里放**作者精修认可**的样本章节或对白片段。/write 写作时把这里当作"这本书该长什么样"的最高参照，优先级高于 style/guide.md 的抽象描述。

## 规则
- 本目录下的 `*.md`（除本 README）= 作者已确认的锚点，/write 必读。
- `candidates/` 子目录 = AI 从 import/ 旧稿或试运行中挑出的候选，文件开头标注 **"待作者确认"**。候选不作为写作锚点。
- 作者确认后，把文件从 `candidates/` 移到本目录，并删除"待作者确认"标记。

## 推荐命名
- `scene-<关键词>.md`：一段完整场景（500–1500 字）
- `voice-<角色名>.md`：某个角色的对白样本（同时抄一份到 bible/characters/ 的"原文样本"）
- `gag-<引擎>.md`：某个喜剧引擎运转得最好的一段

## 每个锚点文件建议格式
```
# 锚点：<标题>
- 来源：<第几章 / 旧稿文件名>
- 好在哪里：<一两句，作者写或作者认可>
---
<原文>
```
