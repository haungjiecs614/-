# 禁用清单（banned）

> /write 写作前必读、写完后自检；critic 审稿时逐条对照。
> 每一条都附"为什么禁"和"改成什么"，因为只禁不教，AI 会换一种同样的腔调。
> 作者可随时追加。新增条目请写明示例。

## 一、陈词滥调句式（AI 腔重灾区）

| 禁用表达 | 示例 | 为什么禁 | 改成什么 |
|---|---|---|---|
| 嘴角勾起一抹弧度 / 嘴角微微上扬 | "洛克嘴角勾起一抹邪魅的弧度。" | 千人一面，没有人物 | 写具体的、只属于这个角色的动作或台词："洛克笑得像刚偷了修道院的捐款箱。" |
| 空气仿佛凝固了 | "话音刚落，空气仿佛凝固了。" | 用宣告代替呈现 | 写一个具体的停顿：谁的杯子停在半空，谁的尾巴不摇了 |
| 一股莫名的情绪涌上心头 | "艾拉心中涌起一股莫名的情绪。" | "莫名"等于作者没想清楚 | 想清楚是什么情绪，用动作演出来，或干脆不写 |
| 不由得 / 不禁 / 忍不住（高频） | "她不由得脸红了。" | 填充词，削弱动作力度 | 直接写动作："她脸红了。" |
| 眸子里闪过一丝…… | "她的眸子里闪过一丝慌乱。" | 眼神描写的万能模板 | 让慌乱落在可见的行为上："她把同一句话说了两遍。" |
| 深吸一口气 | "他深吸一口气，说道……" | 无意义的起手式 | 删掉，直接说话 |
| 心中一凛 / 心头一震 / 瞳孔骤缩 | "洛克瞳孔骤缩。" | 套路化的惊讶表达 | 写他接下来做了什么 |
| 宛如 / 仿佛 / 犹如 + 宏大意象 | "她的声音宛如天籁。" | 空洞的修辞 | 要么用具体、带人物视角的比喻，要么不用 |
| 声音不大，却清晰地传进每个人的耳朵 | — | 网文老套 | 写具体谁听到、谁有反应 |
| 一丝 / 一抹 / 些许（叠用） | "带着一丝不易察觉的笑意" | 模糊化表达，AI 高频 | 写明确的程度或删掉 |
| 他（她）知道，…… | "他知道，这一战避无可避。" | 叙述者代替角色下结论 | 让角色的行动说明他知道 |

## 二、结构类

| 禁用结构 | 示例 | 为什么禁 | 改成什么 |
|---|---|---|---|
| 章末升华总结 | "也许，这就是成长吧。" / "他不知道的是，命运的齿轮已经开始转动。" | 违反"章末是钩子"；后者是假钩子 | 停在一个具体的悬念、危机或尴尬场面上 |
| 连续三连排比 | "他想起了……，想起了……，想起了……" | AI 腔的标志性节奏 | 挑最有力的一个，写透 |
| 每段都用比喻描写情绪 | 连续三段都有"像……一样" | 修辞密度过高，节奏拖沓 | 一章里有一两个好比喻就够 |
| 场景开头写天气 / 环境全景 | "清晨的阳光洒在……" | 网文开场大忌 | 从一句台词或一个动作开场 |
| 用"然而""但是"制造假转折 | 频繁的"然而，事情并没有那么简单" | 宣告转折而非呈现 | 直接写出转折的事件 |
| 段落末尾的总结句 | 段末加一句"这让他明白了……" | 解释已经呈现过的东西 | 删掉 |

## 三、对话类

| 禁用写法 | 示例 | 为什么禁 | 改成什么 |
|---|---|---|---|
| 角色互相说明对方已知信息 | "你也知道，我们被禁制绑在一起，不能离开对方超过……" | 违反 CLAUDE.md 禁止事项，最典型的信息倾倒 | 通过冲突自然暴露信息（例如艾拉试图走远，禁制发作） |
| 反派长篇解释动机 | 反派用三段话讲自己的悲惨身世与计划 | 拖节奏、削弱威胁 | 动机通过行为和只言片语透出；必要时让洛克在反派讲话时打断/走神/吐槽 |
| 对白标签花样化 | "他咆哮道""她娇嗔道""他沉声道"轮番上 | 用标签代替台词本身的力量 | 多用"说"或干脆不用标签，靠台词和动作区分 |
| 角色说话趋同 | 四个人用同一种句式、同一种幽默感说话 | 喜剧引擎失效 | 对照各角色档案的"声纹" |
| 角色说出主题 | "你真是个口是心非的人啊。"（对艾拉） | 把潜台词说成台词 | 让读者自己看出来 |

## 四、喜剧类

| 禁用写法 | 示例 | 为什么禁 | 改成什么 |
|---|---|---|---|
| 叙述者跳出来解释笑点 | "这句话的讽刺之处在于……" / "显然，他完全没意识到自己有多可笑。" | 解释笑点 = 杀死笑点 | 相信读者，笑点落地后立刻切走 |
| "众人都笑了"式效果宣告 | "众人哄堂大笑。" / "这一幕让所有人忍俊不禁。" | 用宣告代替制造笑点 | 写一个具体的人的具体反应，最好也是个笑点 |
| 笑点之后补刀式说明 | 笑点台词后再接一段心理描写解释 | 时机被破坏 | 笑点放在段尾，下一段换节奏 |
| 用"噗""哈哈哈"代替笑点 | 角色连续发笑的拟声词 | 网文低级手法 | 删掉 |
| 网络热梗、现实流行语 | "绝绝子""yyds""泰裤辣" | 破坏西幻沉浸感，且过时极快 | 用世界内的说法 |

## 五、尺度类（番茄平台，硬红线）

| 禁止 | 说明 |
|---|---|
| 露骨的身体与性描写 | 好色只写到口嗨、意淫、计划阶段，镜头在实施前就被打断 |
| 欲望得逞 | 喜剧核心是挫败，不是满足 |
| 任何未成年人相关的暧昧 | 包括外表年幼角色，没有例外 |
| 性暴力、胁迫 | 即使是玩笑口吻 |
| 现实政治、现实宗教指涉 | 世界内的神祇与教会只要不影射现实宗教即可，具体待世界观确定 |
