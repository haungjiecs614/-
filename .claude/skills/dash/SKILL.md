# /dash —— 项目仪表盘

> 说明：原计划名为 `/status`，但 Claude Code 内置了同名命令（显示版本、账号、连接状态），自定义技能会被它遮蔽，所以改名为 `/dash`（dashboard）。

## 步骤
1. 运行 `python3 tools/novel.py stats`，以它的数字为准（不要自己估算字数和次数）。
2. 读取 structure/outline.md 与 state/ledger.md 的"全局"表，确定当前所在卷/篇。
3. 如果 cards/ 中存在尚未写正文的章节卡，读取下一张，取它的主功能和核心冲突作为"下一章预告"。

## 输出格式（简洁，一屏以内）
```
## 📖 项目仪表盘
- 进度：已完成 N 章 / 约 110 章 · 总字数 ____ / 300000（__%）
- 当前：第_卷 · ch___（卷进度 __/__）· 故事内：____
- 流水线：有卡未写 __ · 已写未审 __ · 已写未同步 __

## 🔍 开放悬念（N 个，理想 3–5）
- ……
## 🪤 待回收伏笔（N 个，超期 N 个）
- ……
## 😂 梗使用排行（前 5）
- ……
## ⚠️ 需要注意
- （超期伏笔、梗违规、字数不达标、同步断档、超过 10 章未体检……没有就写"无"）
## ▶️ 下一步
- /____（来自 stats 的"下一步建议"，可补充一句理由）
```

只读，不修改任何文件。
